Panduan Format & Hemat Storage

Essensiana mengekstrak teksnya saja lalu menyimpannya ke Firestore — bukan menyimpan file mentahnya. Ini yang paling murah untuk kuota Firebase kamu.
FormatUkuranRekomendasi
.md (Markdown)Paling kecilTerbaik
.txt (Teks polos)Sangat kecilTerbaik
.docx (Word)SedangBaik, cuma teksnya diambil
.pdfBisa besarHati-hati, hasil urutan teks kadang berantakan

Kenapa bukan simpan file aslinya saja?

Firestore membatasi satu dokumen maksimal 1MB, dan penyimpanan file di Firebase Storage dihitung per GB tersimpan + per GB yang diunduh. File PDF/DOCX/gambar bisa berukuran ratusan KB sampai puluhan MB, sedangkan teks hasil ekstraksinya biasanya cuma puluhan-ratusan KB. Karena itu, Essensiana secara default membuang file mentahnya setelah teksnya diambil, dan hanya menyimpan hasil ekstraksi + jawaban latihanmu.

Format naskah yang dikenali (opsional, tapi disarankan)

Judul modul/bab, tandai dengan salah satu dari ini di awal baris:

# Judul Modul
atau
MODUL 01: Judul Modul
atau
BAB 1 — Judul Bab

Blok latihan/pertanyaan yang bisa diketik jawabannya, bungkus begini:

:::latihan Judul Latihan (opsional)
- Pertanyaan pertama
- Pertanyaan kedua
:::

Kalau naskahmu (hasil dari .docx/.pdf) tidak memakai format ini, Essensiana tetap mencoba menebak bab lewat kata kunci seperti MODUL, BAB, CHAPTER, dan menebak bagian latihan lewat kata LATIHAN. Untuk hasil paling rapi, tetap format .md manual adalah yang terbaik.

Soal upgrade aplikasi

Aplikasi ini didesain supaya kalau kamu mau upgrade fitur, kamu cukup mengganti file index.html di GitHub. File firebase-config.js, manifest.json, service-worker.js, dan folder icons/ dibuat supaya jarang atau tidak pernah perlu disentuh lagi.
